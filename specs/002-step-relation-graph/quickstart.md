# Quickstart: 端到端验证指南

**Feature**: `002-step-relation-graph` | **Date**: 2026-08-31

本指南证明流程框图特性按 spec 验收场景工作。前置条件与开发运行方式同特性 001（`npm install` → `npm run tauri dev`；构建 `npm run tauri build`）。

## 自动化测试

```powershell
npx vitest run                 # 前端：图数据聚合、NodeBox 渲染、分栏联动
cd src-tauri ; cargo test      # 既有 17 项保持通过（本特性零 Rust 改动）
```

预期：全部通过。重点用例：摘要聚合口径与列表一致、derives 边方向 parent→child、共享边按节点对去重且计数正确（含 3 节点共享）、空数据不产生边。

## 手动验收场景（映射 spec）

准备：建工程"框图演示"，构造 4 个节点：A→B→C 成链（B 来源于 A，C 来源于 B）、独立节点 D；向 A 登记 3 个文件、C 登记 1 个与 A 中相同的源文件（共享）、B 登记 2 个文件。

### G. 框图总览（US1 / SC-001）

1. 打开工程 → **预期**：同屏看到框图分栏与节点列表；4 个框纵向排列，A、B 在上、C 在下，连线 A→B→C 自上而下；D 无连线独立呈现。
2. 核对框内摘要：A 框"3 项"及大小、C 框"1 项"，与节点列表工具栏数字一致。
3. 缩放（滚轮）、平移（拖空白）、点"适应视图" → 视图平滑、一键回全图。

### H. 实时联动（US2 / SC-002）

1. 保持框图可见，从文件管理器拖 2 个文件到 B（登记） → **预期** 1 秒内 B 框计数变为 4、大小更新。
2. 在列表新建节点 E（来源于 C） → 框图立即出现 E 框与 C→E 连线，布局自动重排。
3. 编辑 C 的来源改为 A → 连线即时 B→C 变为 A→C。
4. 删除 B（处置：转移文件到 A） → B 框消失，A 框计数 +2。
5. 在框图点选 C → 列表选中 C、登记面板切换；在列表点选 A → 框图 A 框高亮。
6. 对 C 归档（少量文件）→ 批次结束后 C 框待归档/已归档计数刷新。

### I. 画布直接编辑（US3 / FR-015~019）

1. A 框悬停 → 出现"新建下游"；点击 → 对话框来源已预填 A → 命名保存 → 新框与 A→新框连线即时出现。
2. 从"新框"底部拖出连线落到 D 框 → 新框来源变为 D，连线重排。
3. 从 C 框拖线落回 C 自身或其下游 → 被拒绝，提示与列表端一致（防环），数据不变。
4. 拖线中途松手于空白处 → 取消，无残留。
5. 双击任意框 → 编辑对话框；改名保存 → 框内名称即时更新。
6. 框上删除入口 → 既有处置对话框；完成后框消失、两端一致。

### J. 共享文件呈现（US4 / FR-006）

1. A 与 C 间因共享源文件出现**虚线共享标记**（与实线来源连线视觉可区分）。
2. 悬停共享标记 → 显示共享文件名列表。
3. 移除 C 中该共享登记 → 共享标记消失。
4. 把同一文件再登记到第三个节点 → 相关节点对均出现共享标记，计数正确。

### K. 边界与性能（SC-003 / 边界场景）

1. 空工程 → 框图分栏显示空状态与引导。
2. 全独立节点（无连线）→ 正常渲染。
3. 造数脚本构造 200 节点 / 2000 登记文件 → 打开、缩放、平移、点选均 ≤1 秒、无卡顿。
4. 极限缩放（最小/最大）→ 视图可用不空白。

## 验收判定

G–J 全部通过即满足 US1–US4 验收标准；K-3 覆盖 SC-003/FR-014。数字一致性（FR-013）贯穿各场景核对。
