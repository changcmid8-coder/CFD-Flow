## 手动验收场景

准备：工程"图示演示"含链 A→B→C 与独立节点 D，A 与 C 共享同一源文件，各节点登记若干文件。

### L. 归档目录流程图（US1 / SC-001/SC-004）

1. 对该工程执行一次归档（目标目录任选，少量文件即可）→ 归档结果页正常展示。
2. 打开资源管理器进入 `目标目录/图示演示/` → **预期**：存在 `流程图.png`，与各节点子目录并列。
3. 双击图片 → **预期**：无需任何专门软件即可查看；图中 A、B、C 自上而下箭头相连、D 独立成框；每框显示名称、`n 项 · 大小` 与徽章；A—C 间有橙色虚线"共享 1"标记；与软件内框图、目录子文件夹一一对应。
4. 增删一个节点后再次归档 → 图片更新为新结构（同名覆盖）。
5. 归档确认页取消（或无成功文件）→ **预期**：不生成/不更新图片。

### M. 节点预设（US2 / SC-002）

1. 列表入口"新建节点" → 对话框内可见 5 个预设 chips（参考文献/原始几何/网格划分/计算求解/后处理）。
2. 点击"网格划分" → 名称自动填入 → 直接保存 → 节点创建成功，全程 ≤5 秒。
3. 画布入口：某框"新建下游" → 来源已预填该节点 → 再点预设 → **预期**：仅名称填入，来源预填不变。
4. 修改预设填入的名称（如"网格划分V2"）后保存 → 以修改后名称创建。

### N. 失败可见性（FR-005 / 边界场景）

1. 把目标目录指到一个只读位置（或归档中断开网络盘）→ 归档结果或通知区出现图片生成失败的可见警告，且归档文件本身的结果状态不受影响。

## 验收判定

L/M/N 全部通过即满足 US1/US2 验收标准与 SC-001~004；200 节点图片生成耗时（SC-003）以造数抽查为准。
